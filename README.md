# 📚 Library Management System (C++ Basic Version)

A simple console-based library management system built using **only basic C++ concepts (no OOP)**.  
This project allows users to manage a collection of books through a text-based menu.

---

## 🚀 Features
- Add new books (auto-generated IDs)
- Display all books
- Borrow and return books
- Update title or author
- Delete books
- Confirmation before important actions

---

## 🧠 Concepts Used
- Arrays  
- Functions  
- Loops and conditionals  
- Input handling (`cin`, `getline`, `cin.ignore()`)

---

## 💻 How to Run
1. Open the project in any C++ IDE (Code::Blocks, Dev-C++, VS Code).
2. Compile and run the code.
3. Use the menu to manage the library.

---

## 🧩 Future Improvements
